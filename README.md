# analytical_mechanics
Tutorials, Activities, and Code for my Analytical Mechanics class at the University of Colorado Denver

## Interactive pages

- [Brachistochrone visualization](docs/brachistochrone/README.md) - a browser-based comparison of the cycloid and straight-line paths

The optional [Cloudflare class-histogram API](cloudflare/README.md) shares classroom results across
devices using a Worker and D1 database.
