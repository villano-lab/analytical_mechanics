The cycloid solution

Taking downward as positive, the cycloid can be written parametrically as

x = a(theta - sin theta) y = a(1 - cos theta)

The page solves for a and the final value of theta so the curve passes through the selected endpoint. The travel time is then T = sqrt(a/g) thetaf.

Assumptions: point mass, uniform gravity, no friction, and no rotational kinetic energy.
