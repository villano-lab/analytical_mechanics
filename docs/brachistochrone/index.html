How the page evaluates a curve

The draggable points define a smooth trial function y(x). The page samples that curve into short segments and numerically sums dt = ds/√(2gy). Moving a point changes both the path length and how quickly the bead gains speed.

The revealed extremal

The cycloid is evaluated from x = a(θ − sin θ) and y = a(1 − cos θ), with a and θf chosen to reach the same endpoint.

Assumptions: point mass, uniform gravity, no friction, and no rotational kinetic energy.
